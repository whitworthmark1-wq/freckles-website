CLOUDFLARE REDIRECT RULES
===========================
Add ALL of these rules in Cloudflare before going live.
Dashboard > Your Domain > Rules > Redirect Rules > Create Rule

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
RULE 1 — www to non-www (CRITICAL for Search Console)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  When: Hostname equals  www.frecklesbeautyclinic.co.uk
  Then: Redirect to      https://frecklesbeautyclinic.co.uk${uri.path}
  Type: 301 (Permanent)

This fixes the Search Console issue with:
  http://www.frecklesbeautyclinic.co.uk/
  https://www.frecklesbeautyclinic.co.uk/

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
RULE 2 — http to https (CRITICAL for security + SEO)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  When: SSL/HTTPS is Off
  Then: Redirect to      https://frecklesbeautyclinic.co.uk${uri.path}
  Type: 301 (Permanent)

NOTE: Cloudflare also has an "Always Use HTTPS" toggle under
SSL/TLS > Edge Certificates — enable this too. It handles
this automatically without needing a manual rule.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
RULE 3 — Trailing slash removal
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  When: URI Path ends with  /  AND URI Path does not equal  /
  Then: Redirect to      https://frecklesbeautyclinic.co.uk${regex_replace(uri.path, "/$", "")}
  Type: 301 (Permanent)

This fixes the Search Console issue with:
  https://frecklesbeautyclinic.co.uk/contact/  → /contact

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Once the domain is live on Cloudflare, go to Google Search Console
and request re-indexing for each of these URLs:

1. https://frecklesbeautyclinic.co.uk/
2. https://frecklesbeautyclinic.co.uk/about
3. https://frecklesbeautyclinic.co.uk/contact
4. https://frecklesbeautyclinic.co.uk/caci
5. https://frecklesbeautyclinic.co.uk/laser
6. https://frecklesbeautyclinic.co.uk/skincare
7. https://frecklesbeautyclinic.co.uk/dermalogica
8. https://frecklesbeautyclinic.co.uk/beauty
9. https://frecklesbeautyclinic.co.uk/opi
10. https://frecklesbeautyclinic.co.uk/skin-school

For each URL:
  → Paste URL into the Search Console top bar
  → Click "Request Indexing"
  → Wait for confirmation

Also submit the sitemap:
  → Search Console > Sitemaps > Add new sitemap
  → Enter: sitemap.xml
  → Click Submit
